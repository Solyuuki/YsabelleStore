# Thesis Validation Evidence

Store evidence by execution type.

## Manual UI Evidence

Use:

`evidence/manual/<TEST-ID>/`

Example:

`evidence/manual/IT-04/`

## Automated Evidence

Use:

`evidence/automated/<TEST-ID-or-command>/`

Store terminal output, CI references, and machine-readable reports where available.

## SARIMA Evidence

Use:

`evidence/sarima/`

Generated quantitative outputs will be written here once the validation script is implemented.

Do not commit confidential production credentials, secrets, or unnecessary personal/customer information.
