# Product Import Samples

These files support the Sprint 3 M3 product import workflow.

## Files

- `valid-products.csv`
- `valid-products.xlsx`
- `duplicate-sku.csv`
- `duplicate-barcode.csv`
- `invalid-category.csv`
- `negative-stock.csv`
- `missing-required-column.csv`

## Notes

- The valid samples match the import template contract.
- Error samples are intentionally invalid so preview and import validation can be verified.
- The Excel sample uses the same canonical rows as the valid CSV sample.
