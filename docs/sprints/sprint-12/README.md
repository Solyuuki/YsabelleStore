# Sprint 12 — Mobile Point of Sale (MPOS)

Sprint 12 is the active development sprint for YsabelleStore's mobile point-of-sale (MPOS) workstream. Its baseline is the latest approved `main` release.

## Scope

- Define and implement the MPOS experience in reviewable increments.
- Reuse existing POS, inventory, payment, and audit authorities rather than create a competing sales system.
- Preserve storefront/POS concurrency safety and canonical stock validation.
- Maintain usable dark/light modes, accessibility, and responsive operation.
- Record automated and manual QA evidence before release.

## Integration

The integration branch is `sprint/v0.12/sprint-12`. Development changes flow through established task reviews, CI, and release approval. Updating `activeSprint` does not change the application version, deployed runtime, or certified Sprint 11 history.

## Status

Sprint 12 documentation initialized. MPOS requirements and implementation details remain subject to review; no MPOS feature is declared delivered by this activation.
